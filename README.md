#Pagina-Asistente-Educativo

Descripción
Esta es una interfaz gráfica web estática desarrollada para mejorar la experiencia de usuario del agente inteligente educativo. El objetivo principal es ofrecer a los docentes una plataforma sencilla y dinámica para la creación de planeaciones educativas alineadas con los libros, formatos y normativas oficiales de la SEP.

La interfaz actúa como el puente entre el docente y el agente inteligente, facilitando la generación de material didáctico personalizado.

Funcionalidades Principales
El sistema incluye un formulario inteligente diseñado para capturar los parámetros esenciales de la planeación:

Gestión de Contenido:
Selección de Campo Formativo (materia).
Referencia directa a Libros de Texto.
Definición del Proyecto específico a trabajar.
Flexibilidad Temporal: Configuración de planeaciones por periodos:
Semanal.
Quincenal.
Mensual.
Automatización: Botón de generación automática de planeaciones mediante el agente inteligente.
Personalización: Sistema de Registro e Inicio de Sesión para que cada docente pueda guardar su historial de planeaciones y preferencias.
